# CloudPelizzon Core 0.13.0

Data: 28/09/2026

## Principais mudanças

- Integração do CP-ENERGY como módulo interno da plataforma.
- Navegação superior condicionada aos direitos de licença.
- Roteamento para abertura dos módulos licenciados dentro do shell CloudPelizzon.
- Correções de sincronismo de licença e de ciclo de renderização.
- Padronização dos cards ativos e da vitrine comercial.
- Integração com a Central de Documentação e links versionados.
- Estrutura de documentação organizada por componente e versão.

## Documentação

https://documentacao.cloudpelizzon.com.br/notas-de-versao/core/0.13.0

## Padronização global de datas R5.1 — 28-09-2026
- Datas visíveis padronizadas para DD-MM-AAAA em todos os painéis CloudPelizzon.
- Timestamps visíveis padronizados para DD-MM-AAAA HH:MM[:SS].
- Valores internos, APIs e banco permanecem ISO quando tecnicamente necessário.

## Administração e status visual R5.2 — 28-09-2026
- Update Center: módulo atualizado passa a usar badge verde.
- Update Center: módulo com versão disponível passa a usar badge laranja e texto “Desatualizado”.
- License Center: canais exibidos em português, mantendo os valores técnicos internos stable/pilot/beta.
- Release Center e Documentação reorganizados para o modelo atual do ecossistema CloudPelizzon.
- Registros locais de teste Smoke Test R2 / TEST-* removidos do backoffice.
- Documentation Center: um único ícone padronizado por item de menu.
